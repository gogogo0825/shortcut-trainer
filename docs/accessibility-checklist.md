# アクセシビリティ手動確認

WCAG 2.2 AAを目標とした確認項目です。自動検査だけで適合を保証しません。実行環境・結果・未解決点を確認者が記録してください。

- [ ] WindowsのChrome・Edgeで、Tab／Shift+Tab／Enter／Spaceのみで全画面を操作し、スキップリンクとフォーカスの位置・表示を確認する。
- [ ] ガイドの誤答・正答、クイズの正答・誤答・スキップ、次の問題、結果画面の通知とフォーカスをスクリーンリーダーで確認する。
- [ ] NVDAまたはナレーターで見出し・ナビゲーション・入力名・正誤・グラフの代替情報を確認する。
- [ ] ライト・ダーク両方で文字、フォーカス、ボタン、状態表示のコントラストを確認する。色だけで正誤を判別させないこと。
- [ ] ブラウザーの200%拡大、文字サイズ「大きい」、狭い画面で文章や操作が欠けず利用できることを確認する。
- [ ] スマートフォン・タブレットで4択、復習、分析、問題管理を実機操作する。
- [ ] OSのアニメーション抑制を有効にし、不要な動きが抑制されることを確認する。
- [ ] 実機のJISキーボード、IME、複数段階入力、OS／ブラウザー予約キーと代替採点を確認する。

自動検査は `npm run e2e` 内でaxe-coreを使い、ホームのライト／ダーク、設定、スマホのクイズ・分析・復習、問題管理を対象に実行します。ブラウザー・支援技術の実機確認の代わりにはなりません。
