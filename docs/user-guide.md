# ユーザーマニュアル

## 基本操作
ホームの「練習を始める」またはカテゴリを選び、モード・カテゴリ・出題順・セッション長・採点方法を設定します。問題数は5/10/20/50問、制限時間は1/3/5/10分、または無制限です。選択した問題が指定の長さより少ないときは繰り返します。無制限は「セッションを終了」で終了します。

ガイド練習は正解キーを表示し、不正解や複数段階入力の時間切れ後も同じ問題を再挑戦できます。クイズは正解を隠し、初回回答を採点します。回答後は正解・説明・採点方法を表示します。

キーボード入力は「回答開始」を押すか回答欄を選んでから行います。回答欄以外では入力を採点せず、TabとEscapeは通常の画面操作に使えます。JISキーボード図の表示を切り替えられます。青は押下状態、ガイド練習の黄色は正解キーです。複数段階入力は各段階の間隔が1.5秒を超えると時間切れになります。

OSやブラウザーの予約キーは回答欄に届かない場合があります。その場合、採点方法を4択または自己申告に切り替えてください。自己申告は自動検出ではありません。各回答は採点方法・初回か再挑戦かを区別してこの端末のIndexedDBに保存します。時間制限の終了、スキップ、アプリ内のページ離脱も区別して記録します。一時停止中とタブが非表示の時間は計測から除外します。

初回回答が正解すると、採点方法を問わず10 XPを獲得します。再挑戦・不正解・スキップ・未回答には付与されません。100 XPごとにレベルが1上がります。連続初回正解はセッション内で数え、初回不正解またはスキップなどで途切れます。連続学習日数は採点済み回答の日を端末のローカル日付で数えます。以前の履歴にはさかのぼってXPを付けません。

「設定」ではライト・ダーク・端末設定への追従と文字サイズを選べます。ブラウザーの拡大機能も利用できます。スマートフォンではセッション開始前の採点方法で4択または自己申告を選んでください。

標準問題と独自問題の確認状況は問題一覧に表示されます。出典確認済みでも実機確認済みとは限らず、未確認の項目の正確さは保証されません。

## 実機検証
「実機検証」で標準問題をカテゴリ・難易度・実機検証状況から探し、「検証する」を選びます。「次の未確認問題へ」も利用できます。必要に応じて入力欄でキーを試せますが、ブラウザーが入力を検出できたことと対象アプリで操作が成功したことは別です。OSやブラウザーに予約されたキーは捕捉されず、実際の操作が発動することもあります。安全なテスト環境で確認してください。

WindowsのJISキーボードと対象アプリで実際に操作し、結果（正常動作・動作不一致・検証不可・未確認）、日時、OS・ブラウザー・対象アプリのバージョン、キーボード配列、備考を登録します。捕捉できない場合は入力検出を「イベントを検出できない」にし、必要なら結果を「検証不可」としてください。正常動作は対象アプリで期待どおり動いたことを人がチェックして登録した場合のみです。自動テストの成功は実機確認ではありません。

進捗は各問題の現行revisionに対する最新登録の自己申告を集計します。旧revisionの記録は履歴に残りますが、現行の確認済みには数えません。「検証結果をJSON出力」は全revisionの検証記録を出力します。端末の学習履歴や標準問題の出典状態は変更されません。

## 学習分析
「分析」から採点方法・モード・初回／再挑戦別の正答率、キーボード回答時間、日次推移、カテゴリ進捗、履歴と弱点順位を確認できます。スキップ・未回答・中断は正答率に含めず、4択や自己申告の時間をキーボードの速度と比較しません。タブ非表示や一時停止があった回答は速度集計から除外します。

習熟度と復習予定はクイズの初回キーボード回答に限定し、直近の正誤と速度から計算します。問題ごとの目標時間が設定されていない場合、速度は中立値です。実機未確認の問題も含まれており、習熟度は目安です。分析から「復習一覧」を開き、期限が到来した問題を個別に練習できます。ガイドや4択・自己申告の回答は表示されますが、習熟度や復習予定には反映されません。

出題順の「適応型」は期限到来、低習熟、未学習の順に選び、複数問題があるときは同じ問題を連続させません。連続学習日数は端末のローカル日付で計算し、今日または昨日から連続した日数です。端末間のデータは自動同期されません。

## 問題管理とデータ移行
「問題管理」で独自問題のJSONを作成・編集し、練習できます。新規IDは重複できず、編集時はIDを維持してrevisionを1増やします。履歴のある問題はカテゴリと操作名を変更できません。削除は無効化であり、履歴と習熟度は残ります。

問題インポートはJSONの問題配列またはCSVを使用します。CSVの列は問題JSONと同じ名前で、`platform`、`appVersions`、`steps`、`gradingModes`、`source`、`tags`はJSON文字列としてCSVの規則に従い引用してください。`appVersions`と`targetTimeMs`は空欄にできます。ファイルは2 MiB以下です。プレビュー後に既存IDを保持するか、より大きなrevisionで更新するか選択します。標準IDや履歴に残る未登録IDは取り込めません。

JSONバックアップには回答、セッション、習熟度、独自問題、実機検証記録、IndexedDBの設定と実績が含まれます。形式version 3で保存し、従来のversion 1・2も復元できます。テーマなどlocalStorageの設定、内部メタデータ、標準問題は含みません。復元は2 MiB以下のバックアップをプレビューし、確認後に実行します。記録が増えて上限を超えると復元できないため、サイズを確認してください。既存の設定・実績は保持し、回答・セッション・独自問題・実機検証記録が同じIDで異なる場合は全体を中止します。回答を追加した問題の習熟度は履歴から再計算します。端末間の自動同期はありません。

ブラウザーの保存データはオリジン（サイトのスキーム・ホスト・ポート）ごとに分かれます。開発サーバーのデータは将来の公開サイトへ自動移行されません。移行する場合は元の環境でバックアップを作成し、新しい環境で内容と衝突処理を確認して復元してください。一般向けの独自問題入力フォームは未実装で、現在はJSONを編集します。
